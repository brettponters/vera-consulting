How to install

Gmail: Settings → See all settings → General → Signature → Create new. Open this file in a browser, select from START to END, copy, paste into the signature box.

Apple Mail: Mail → Settings → Signatures → +. Same copy/paste. Uncheck "Always match my default message font."

Outlook (desktop): File → Options → Mail → Signatures → New. Paste. Outlook may strip the SVG V mark — if so, the wordmark "VERA" + dot still renders cleanly.

Superhuman / HEY / Spark: Settings → Signature → paste HTML.
